## 기능 (요구사항 매핑)

| 요구 | 구현 |
|------|------|
| 전체 인원 실시간 지도 표시 | 카카오맵 + `event.{id}.control` 구독, `participant.location`으로 마커 이동 |
| 역할별 필터 | 좌측 체크박스 → 마커 표시 토글 (참가자/운영진/경찰/자봉(코스)/자봉(구급)/구급대) |
| 신고 접수 목록 | `request.created` 실시간 prepend + `GET /api/events/{id}/requests` |
| 신고 위치 고정 표시 | 신고 스냅샷 좌표 = 점멸 핀(인원 마커와 구분), 클릭 시 상세 |
| 지령 배정 | 신고 클릭 → 가용 구급대원(거리순) 선택 → `POST /api/requests/{id}/dispatch` |
| 출동 현황 확인 | `dispatch.updated` 실시간 → 보드 카운트/타임라인 갱신 |
| 처리 완료 기록 | 완료 지령은 이력으로 이동, 처리시간(접수→도착→완료) 표기 |
| 행사 종료 후 기록 다운로드 | CSV/Excel: 신고·지령·동선(location_pings) 내보내기 |

## 실시간 마커 처리
- 초기 로드: `GET /api/events/{id}/participants` → `event_participants`의 `last_lat/last_lng`+role+online으로 마커 일괄 생성(이력 미조회).
- 갱신: Echo `participant.location` → 해당 마커 좌표만 이동(전체 리렌더 금지). 마커 풀 재사용.
- online/offline: `last_seen_at` 타임아웃 → 마커 흐리게/제거.
- 대규모(수백~수천 인원): 뷰포트 클러스터링 + 화면 밖 마커 가상화.

## 기록 다운로드 (요구 마지막)
- 기존 `ProjectController::exportCsv` 확장 또는 신규 `EventReportController`:
  - 신고 리포트: 유형·시각·위치·처리시간·담당.
  - 지령 리포트: 전이 타임라인(배정→수락→출동→도착→완료).
  - 동선(선택): `location_pings`를 참가자별 GPX/CSV. 대용량 → 비동기 생성 후 다운로드 링크.
- 개인정보: 행사 종료 후 위치이력 보존기간 정책(자동 파기) 명시 필요(09 리스크).

## 기술 선택
- 관제는 인터랙션이 무거우므로 **Vue SPA 영역**(기존 CDN-per-page 방식 대신 Vite 번들 1개). 라우팅은 단일 관제 페이지 + 패널.
- `controller`/시스템 `admin`만 접근(서버 가드 + 라우트 미들웨어).

## 수용 기준 (발췌)
- [ ] 한 지도에서 전 인원이 역할 색상으로 실시간 이동한다.
- [ ] 역할 필터가 즉시 적용된다.
- [ ] 신고가 뜨면 목록·지도에 즉시 나타나고 고정 핀으로 표시된다.
- [ ] 신고에서 구급대원을 골라 지령을 배정할 수 있다.
- [ ] 출동 현황(배정/출동/도착/완료)이 실시간 집계된다.
- [ ] 행사 종료 후 신고·지령·동선 기록을 내려받을 수 있다.
