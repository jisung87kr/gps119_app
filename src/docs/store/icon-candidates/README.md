# 앱 아이콘 후보 (초안)

현재 앱 아이콘은 **Capacitor 기본 로고**다(플레이스홀더). 아래는 교체 후보이고,
채택되면 iOS `AppIcon.appiconset` · Android 적응형 아이콘 · 웹 PWA `icon-192/512.png`
전부에 같은 원본에서 생성해 넣는다.

브랜드 색은 앱의 `--color-brand-600`(`#0e6e7c`)을 그대로 쓴다.

| 안 | 구성 | 비고 |
|---|---|---|
| A | 틸 배경 · 흰 핀 · **빨간** 십자 | 🔴 **쓰지 말 것** — 아래 참조 |
| D | 틸 배경 · 흰 핀 · 틸 십자 | 단색. 작은 크기에서 가장 또렷하다 |
| E | 틸 배경 · 흰 핀 · 맥박선 | 구조·의료 성격이 더 분명하나 20px 대에서 뭉갠다 |

## 🔴 A 안을 쓰면 안 되는 이유

**흰 바탕에 빨간 십자는 「적십자 표장」**이다. 제네바협약과 **대한적십자사 조직법
제25조**로 보호되며, 무단 사용은 처벌 대상이다. 의료·구조 성격의 앱이라 오히려 더
위험하다 — 스토어 심사에서 걸리지 않더라도 법적 리스크가 남는다.

보호 대상은 **«흰 바탕 + 빨강» 조합**이므로 색만 바꾸면 해소된다(D 안).
비교용으로 남겨둔 것이지 후보가 아니다.

## 만든 방법

`compare.png` 는 120px 로 줄인 비교판이다 — **아이콘은 홈화면 크기에서 판단해야
한다.** 1024px 로만 보면 셋 다 좋아 보인다.
